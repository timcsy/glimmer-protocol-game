# 邊玩邊學程式遊戲計畫

## 願景

打造一款「首先是好玩的遊戲」的作品，讓玩家在探索、解謎、冒險與故事中自然接觸程式概念。學習應融入遊戲世界與玩法，不讓玩家感覺自己只是在做一連串課程題目。

玩家可以透過編寫或組合簡單指令來影響世界，例如修理機器、設置陷阱、指揮夥伴或控制機器人。程式概念本身是解決遊戲問題的工具：例如讓機器人巡邏時接觸重複執行，遇到敵人時躲避則接觸條件判斷。

## 設計方向

- **遊戲體驗優先：** 以探索、挑戰與故事作為主要體驗，學習自然發生在遊玩過程中。
- **學以致用：** 程式指令要能改變遊戲世界，並幫助玩家完成具體目標。
- **循序引入：** 先從少量、直觀的指令與問題開始，再逐步引入程式概念。
- **保持選擇空間：** 程式輸入方式尚未決定；可評估直接輸入程式碼、拖拉指令或積木式組合對遊戲節奏的影響。

## 路線圖

### 目前狀態

目前已有兩個可玩的序列與循環關卡，玩家可刪除單一指令、執行程式並取得即時回饋；完成第一區會解鎖第二區。專案已發布於 GitHub Pages。目標玩家先設定為零程式經驗的初學者，輸入方式採視覺指令方塊，再視後續需求逐步加入文字程式碼。
